NEON RPL1 — CYBER CITY
Website kelas XI RPL 1 | SMKN 1 Sampit

STRUKTUR FOLDER
NEON_RPL1_CYBER_CITY/
├── html/
│   ├── index.html       (halaman beranda)
│   ├── anggota.html     (daftar 33 anggota kelas)
│   ├── coding.html      (terminal animasi live coding)
│   ├── galeri.html      (galeri foto)
│   └── profil.html      (identitas kelas dan wali kelas)
├── css/
│   └── style.css        (seluruh desain dan animasi)
└── foto/
    ├── foto-kelas-1.svg (gambar pengganti)
    ├── foto-kelas-2.svg (gambar pengganti)
    └── foto-kelas-3.svg (gambar pengganti)

CARA MEMBUKA
1. Ekstrak file ZIP.
2. Buka folder NEON_RPL1_CYBER_CITY.
3. Masuk ke folder html.
4. Klik dua kali index.html atau buka dengan browser.

CARA MENGGANTI FOTO
1. Simpan foto milik kelas ke folder foto.
2. Buka html/galeri.html.
3. Cari foto-kelas-1.svg, foto-kelas-2.svg, atau foto-kelas-3.svg.
4. Ganti nama file pada atribut src sesuai nama foto baru.
5. Pastikan nama file dan huruf besar/kecil sama.

CATATAN
- Website menggunakan HTML dan CSS saja, tanpa JavaScript.
- Efek hujan, lampu sirine visual, hover, dan animasi mesin ketik dibuat dengan CSS.
- Efek sirine berupa visual lampu merah-biru, bukan suara sirine.
- Foto galeri adalah ilustrasi placeholder yang boleh diganti.
- Nama wali kelas diambil dari daftar hadir yang diberikan: Arif Rahmadhani.
- Untuk mengganti data anggota, edit bagian kartu anggota pada html/anggota.html.
- Google Fonts memerlukan koneksi internet; jika offline, website memakai font cadangan.
